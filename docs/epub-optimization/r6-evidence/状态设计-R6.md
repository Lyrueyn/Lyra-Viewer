# R6 状态设计：view 提交、操作账本、凭据与兼容

## 1. 核心不变量

1. **导航提交是原子边界**：`state.view` 只在下述全部成功后才替换：prepare 完成、资源/fonts ready、DOM 装载、layout 完成、目标定位/高亮完成、旧 intent 未失效。任何失败/取消/关闭都保留旧 `state.view` 与旧稳定锚点；DOM 若已被候选替换，必须完整恢复旧视图，不能 ready/capture 来自候选。
2. **位置只从已提交 view 采集**：`rememberStablePosition`/`flushSave` 在导航未提交、取消或 finalizing 时不得调用 `capturePosition()` 读取候选 DOM；使用 `state.committedPosition`。UI ready、页码、spine、prepared、paginator.sectionIndex 必须同属一个 view 对象。
3. **关闭先结算再冻结**：阻止新输入/open，settle 页码与动画目标（settle 先于 cancel），再取消调度/定时器/资源等待，冻结最后已提交快照；finalize 后旧任务全部走陈旧检查，不再写 DOM/位置/成功 ack。
4. **关闭结果按操作账本**：每个位置/偏好操作有独立状态与最终证明；A 书失败的 failedSave 不被 B 书成功清除。整体成功仅当所有未完成用户操作有持久化完成证明或真实较新已落盘 superseded；interact/metadata/STALE_INTERACTION/清空错误都不算。
5. **位置操作身份在意图产生时冻结**：operation package 含 bookId/openIntent/token 来源/sequence/operationId/opVersion/位置/基准 positionRevision；同一失败操作跨 flush、换书前、重开、timeout 重试沿用；新用户交互才生成新包。
6. **偏好凭据保存授权范围与字段终态**：每条完成凭据含 grant.Fields 全集与每字段 applied/idempotent/superseded/value；活跃 grant 回收后同 token/同值重试重放完整结果；未知字段/不同值仍拒绝。
7. **本地格式按版本+结构双重校验**：未知 version/结构视为不可读，不写回、不覆盖原字节；恢复合法原件后重新验证并操作。
8. **可见模型 = 清洗后有效样式 + 浏览器实际可见内容**；显示/搜索/高亮共用清洗结果；HTML 高亮用安全 mark，SVG 文字使用 SVG 命名空间受支持的原生绘制标识（不塞 HTML mark 导致命中消失）。
9. **版本降级完成安全可用生命周期**：只承接约定 v1/v2 的 ready/error，不接旧持久化命令；拒绝持久化降级 local，但加载层必须按当前受信 session/source/loadId 解除，不能挡住可用正文。

## 2. view 提交模型

```text
state.view = {
  bookId, openIntent, docToken,
  spineIndex, totalPages, pageIndex, pageCount,
  anchor, committedAt, ready
}
state.committedView = state.view
state.navPending = { intent, candidateToken, oldView }
```

- `beginNavigation` 冻结 oldView 与 oldCommittedPosition，`state.ready=false`。
- `paginator.setSection` 在候选成功时返回 `view`；失败/取消返回 `{ok:false, restore:true}`，reader 调 `paginator.restoreView(oldView)`，恢复后才置 ready。
- `commitView` 同步 state.spineIndex/ready/分页 UI；只有这里之后 `captureAnchor` 可发布给稳定位置/保存。
- finalizing 时如果 navPending 存在，直接使用 oldView.committedPosition 冻结，不等待候选。

## 3. 关闭操作账本

- `state.ops` / `state.failedSaves`：book 级位置操作保留身份、状态、证明修订；`state.prefsOps` 保留每个 grant 的字段/值/状态。
- `finishAndAck`：
  1. finalizing=true，冻结输入/open；
  2. settle pageInput + animation target（先 settle 后 cancel）；
  3. 结算当前 view/旧视图稳定位置；
  4. 停 timers/rAF/resource listeners/nav；
  5. flush 位置与偏好（并行有界预算）；
  6. 计算 `allOpsSettled`；未完成返回 `ok:false` + 可见诊断。
- 失败快照不因切书删除；B 成功只清 B。

## 4. 兼容/格式/凭据

- 协议 v3 保持 fieldResults/positionSubmitRevision/frozenFinalize；v2/v1 只承接受信 ready/error 生命周期（能力不足拒绝持久化/local），不允许旧 save 命令进入新 store。
- 本地 `version` 支持已知 1/旧数组对象；未知版本拒绝读写并保留原字节；合法恢复后清 corrupt 并重试。
- 完成凭据包含 `grant.Fields` 全集和每字段 status/value；容量压力时只回收安全 superseded 未完成 grant，最后意图可结算。
