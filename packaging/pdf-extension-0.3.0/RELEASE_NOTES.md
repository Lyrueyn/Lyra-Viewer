## PDF 阅读器 0.3.0

本次更新改善大文档阅读、缩放与跳页稳定性，并补齐文字查找和目录导航。

### 新增

- 文字选择与复制、全文查找和匹配高亮，支持上一个/下一个结果。
- PDF 内置目录导航、页面旋转和整页显示。
- 密码保护文档的密码输入、错误重试与取消。
- 天依蓝深色工具栏和窄窗口布局；支持 Ctrl+F 查找、Ctrl+滚轮缩放等快捷操作。

### 优化与修复

- 优先绘制可见页面，限制同时渲染的任务数量，并释放远处页面的画布，减少长文档阅读中的资源累积。
- 正确处理横竖混排和自带旋转的页面，文字选择与搜索高亮同步旋转。
- 连续缩放、调整窗口及切换侧栏时保留页内阅读位置，修复适应宽度状态丢失。
- 修复低倍率下文末“上一页”跳不动，以及较慢的目录、搜索或渲染任务覆盖后续跳页的问题。
- 页码输入停顿后跳转但保留输入焦点，避免打断多位页码输入。
- 修复单页文件、含百分号的文件名、损坏文件恢复，以及加载完成通知宿主的问题。

### 安装与更新

在璃鸢镜的扩展中心刷新并更新 **PDF 阅读器**，或下载下方 `lyra-ext-pdf.zip`。适配璃鸢镜 1.1.12 的扩展宿主。

更新后关闭已打开的 PDF 窗口，再从书库打开文档即可使用新版。无需重新安装主程序。

扫描件需要自身含文字层才能复制或查找；本扩展不进行图片文字识别。
