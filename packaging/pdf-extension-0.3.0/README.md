# 璃鸢镜 PDF 阅读扩展

独立网页扩展，使用本地 PDF.js 3.11.174。入口为 `index.html`，由璃鸢镜的 WebView2 宿主打开，也可用普通浏览器通过本地 HTTP 服务测试。当前版本：**0.3.0**。

## 阅读功能

- 连续滚动、页码跳转、按需绘制的缩略图、PDF 内置目录。
- 文字选择与复制；全文查找及高亮，支持跨文字片段匹配。
- 适应宽度、整页显示、自定缩放（25%–500%）、旋转、夜间显示。
- 拖入或选择 PDF；密码保护文档可以输入密码、重试或取消。
- 窗口缩放、侧栏开关、连续缩放时保留页内阅读位置。

快捷键：`Ctrl+O` 打开，`Ctrl+F` 查找，查找框 `Enter` / `Shift+Enter` 切换匹配，`Esc` 关闭查找；`←` / `→` 上下页，`↑` / `↓` 小幅滚动，`PageUp` / `PageDown` / `空格` 按屏滚动，`Home` / `End` 首末页，`+` / `-` 或 `Ctrl+滚轮` 缩放，`0` 适应宽度，`R` 旋转。

扫描件必须本身含文字层才能复制和查找。本扩展不进行图片文字识别，不提供批注编辑或 PDF 表单填写。内置目录为空时显示明确提示。

## 0.3.0 的关键修正

- 按每页真实尺寸处理横向、纵向和自带旋转的页面，文字层同步旋转。
- 主页面最多两个并发渲染任务，缩略图一个；先绘制可见页面，再预取相邻页面。
- 单页画布设像素上限，主画布缓存目标为 8 页 / 24M 像素，缩略图目标为 28 页；可见页优先，超出预算的预取页不进入渲染队列。浏览后离开远处页面会释放画布与文字层；这些限制不是整个浏览器进程的内存上限。
- 新画布绘制完成再替换旧画布；旧任务可取消，不对正在绘制的画布改尺寸。
- 更换文档、连续跳页和目录异步解析都有代次检查；较早的搜索或目录请求不能覆盖用户较新的导航。
- 修复适应宽度状态丢失，以及低倍率下文末上一页被自动页码检测改回最后一页。
- 页码停输后跳转但保留输入焦点；回车和失焦完成输入；不再强制打断多位页码输入。
- 修复单页文档越界、文件名含 `%` 时重复解码、打开失败后按钮和旧页面残留，以及加载完成未通知宿主。

## 目录和宿主约定

- `index.html`：页面结构；`reader.css`：样式和文字层定位；`reader.js`：文档生命周期、渲染、导航和查找。
- `lib/`、`cmaps/`、`standard_fonts/`：随扩展分发的本地 PDF.js 及字体资源。
- 宿主传入 `?file=document.pdf&name=<经过URL编码的真实文件名>`，兼容 `?pdf=`。
- 首屏完成或打开失败后发送 `{ type: "lyra-book-ready" }`，不发送会触发宿主重复投喂的 `lyra-ready`。
- 宿主每次打开文档会复制扩展到临时目录，因此更新安装文件后，已打开的窗口仍使用旧副本；关闭 PDF 窗口后重新打开即可使用新版。
- 不依赖跨窗口浏览器本地存储：当前宿主每个窗口使用随机虚拟域名，因此本版没有承诺跨窗口阅读进度记忆。

## 验证

使用 Node.js 和已有 Playwright：

```powershell
node tests/smoke.cjs
```

如果工具不在默认路径，可以设置 `PLAYWRIGHT_MODULE`（Playwright 模块目录）和 `LYRA_BROWSER_PATH`（本机 Edge/Chromium 可执行文件）。可选 `LYRA_TEST_PDF` 指向真实 PDF，供本机附加验证。测试不上传文件，不修改书库。

测试会生成混排、旋转、180 页、单页、纯图形、损坏及加密 PDF，并覆盖并发缩放、25% 缩放静止收敛、末尾跳页、目录和搜索的延迟竞态、密码错误重试/取消等。测试结果和截图写入忽略版本管理的 `artifacts/`。

2026-10-26：本机 Microsoft Edge（无界面模式）完成 16 组浏览器回归，无未捕获页面异常；附加验证使用本机 36 页真实 PDF。180 页文档遍历后采样为 2 张主画布、28 张缩略图，主画布 9,228,660 像素（约 35.2 MiB，不含浏览器、解码器和其他资源）。WebView2 的消息接收通过相同接口模拟检查；不等同于完整桌面宿主界面验收。

## 打包

压缩包根目录应直接包含 `extension.json`、`index.html`、`reader.css`、`reader.js`、`LICENSE`、`lib/`、`cmaps/`、`standard_fonts/`，不要再套一层目录。不要打包 `.git/`、`tests/` 或 `artifacts/`。

扩展源码保留在独立仓库，不并入璃鸢镜主程序仓库。
