【B 站 CC 字幕】
  · B 站视频下载时会自动抓 CC 字幕（含 AI 字幕），文件如「视频名.auto.zh.srt」
  · 播放时同样可用控制条「语言」按钮切换

【字幕（YouTube / yt-dlp 支持的站点）】
  · 下载视频时会把两种字幕都抓下来：
    ① 人工字幕（视频作者/社区上传的多语言 CC）→ 文件如「视频名.zh-CN.srt」
    ② 自动生成字幕（YouTube 机翻/识别）→ 文件如「视频名.auto.en.srt」
  · 播放器自动选中人工中文字幕；控制条「语言」按钮点一下可切换（标签会显示 人工/自动）
  · 设置页也有「字幕语言」下拉可选；「字幕 开/关」控制显示
  · 支持 SRT / VTT / ASS；字幕文件放视频旁边、名字前缀一致即可自动识别
    存成「视频名.zh-CN.srt」这种文件，和视频放同一个目录
  · 播放时自动加载：控制条出现「字幕 开」按钮（天依蓝=开），点一下可关
  · 支持 SRT / VTT / ASS 字幕文件（放在视频旁边、名字前缀一致就能自动识别）
  · 字幕开关状态会记住（下次打开沿用）
【YouTube 播放列表（list=…）】
  · 粘贴带 list= 的 YouTube 链接 → 解析会显示「播放列表：共 N 个视频」
  · 点「⬇ 下载整个播放列表」→ 自动下完所有视频，并在「合集」页自动建一个同名本地合集

【YouTube 需要登录时（风控）】
  · 下载页有红色按钮「▶ 登录 YouTube 获取 Cookie」：点它会弹出内置浏览器
  · 在窗口里登录 Google 账号（YouTube 与 Google 共用登录态），登录成功后会自动抓 Cookie 并保存
  · 之后解析/下载 YouTube 都会带着这个 Cookie（解决 Sign in to confirm you're not a bot）
  · 「清除 YouTube Cookie」可以回到免登录模式

【下载支持哪些站点】
  · B 站：项目自带零依赖通道，配好登录 Cookie 可下 1080P+ / 4K / Hi-Res
  · YouTube 及其它 yt-dlp 支持的站点：走 yt-dlp 通用通道（安装版已内含 yt-dlp）
    ★ 前提是本机能访问该站点。中国大陆直连 YouTube 需要代理，否则解析会提示访问不了该站点
    ★ 非 B 站视频：解析后可选画质是「720P / 480P / … / 最佳画质（自动）」；不能选 Hi-Res、也没有合集
    ★ 下载目录与 B 站相同（可用「打开下载文件夹」查看）
一、安装 / 二、播放操作提示
  · 倍速：视频窗底部拖「倍速」滑条（0.5× ~ 4.0×，连续可调、保持音高）
  · 点一下倍速数值可立刻回到 1.0× 原速
  · 音量：拖音量滑条；空格暂停；←/→ 快退快进
  · 📋 视频信息：视频窗右侧最右边「信息」tab = 当前视频的详细信息（文件大小/容器/时长/码率/
    视频编码/分辨率/帧率/像素格式/位深/HDR/色彩、音频编码/采样率/声道/位深/码率、标签、当前倍速/音量）
  · 📌 置顶（Pin）：视频窗底部「📌 置顶」按钮 = 让视频窗钉在所有窗口最上层
  · 📌 节点图窗口也有「📌 置顶」：开了之后主窗口会解冻，可以边看视频边改节点
  · 视频窗置顶时打开节点图：会自动把节点图置顶、并临时取消视频窗置顶（不会互相压住），
    关掉节点图后视频窗的置顶会自动恢复

三、设置 B 站 Cookie（★ 现在有真·自动获取）
────────────────────────────────────────────
【方式一：自动获取（推荐）】
  1. 播放器 → 左侧「设置」→「🔑 高清下载设置（B站登录 Cookie）」
  2. 点「🔑 自动获取 Cookie」
  3. 会弹出一个内置浏览器窗口，里面是 B 站登录页
     → 用手机扫码 / 账号密码 / 微信登录 都行
  4. 登录成功后，程序会自动抓取 Cookie 并保存，窗口自动关闭
  5. 右侧状态变成「已登录：<昵称>（可下1080p / 大会员可下4K）」
  ★ 这个功能用 Windows 自带的 WebView2 实现，不需要 Node.js / Playwright

【方式二：手动粘贴（自动获取失败时用）】
  1. 浏览器打开 bilibili.com 登录 → F12 → Application（应用）→ Cookies → bilibili.com
  2. 复制 SESSDATA 的 Value（下 4K 再复制 bili_jct、DedeUserID、buvid3）
  3. 粘贴到输入框（或点「从剪贴板粘贴」）→ 点「💾 保存 Cookie」

★ 「怎么获取？」按钮会弹窗再讲一遍步骤
★ 「清空」按钮清掉已存 Cookie（回到 480p）

【YouTube 播放列表画质】
  · 每条下拉默认是「最佳画质（自动）」= 该视频能拿到的最高画质；想限制画质再手动选具体档位
  · 以前探测失败（风控只返回低清格式列表）时默认会下低画质，现在默认走"最佳画质"不会中招

【AI 增强（AI 音频超分 / 人声降噪 / AI 视频超分 / RIFE 补帧）—— 需要一键装依赖】
  · PyTorch 等运行库约 2~3 GB，受体积限制不随安装包提供，所以默认这四项是灰的（节点图里不显示）
  · 用法：播放任意视频 → 右侧「增强任务」tab → 最上面的「AI 增强依赖」卡片 → 点
    「⬇ 一键下载 AI 依赖（自动匹配显卡）」→ 等进度条走完（第一次较久，看网速；装一次以后不再下载）
  · 会自动检测显卡/驱动选择对应版本：如 RTX 50 系 + 新驱动 → CUDA 13.0（cu130）；
    没有 NVIDIA 显卡则装 CPU 版（能用但慢很多）；检测到装了 CPU 版但机器有 GPU 会自动重装 CUDA 版
  · 已装好/正在装时再点按钮不会重复下载（会提示"正在安装中"或"已装好"）；
    中途失败可以直接再点一次（已装好的包会跳过）
  · 装好后「增强链 → 打开节点图窗口 → ＋ 加节点」里就能看到这四项；模型权重已随安装包提供，不用另下
