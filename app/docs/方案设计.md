# 本地歌单器 · 方案设计文档

> 版本：v1.0（2026-08-31）｜状态：已确认，开始落地
> 决策记录：C++(Qt6+libmpv) 主程序 + Python 子进程后端 + 本地 AI 增强

---

## 1. 产品定位

一款装在本地电脑的「媒体库 + B 站体验」二合一应用：

- **本地音频**：自由导入本地音频文件，做成歌单播放
- **B 站视频**：粘贴链接一键下载（含弹幕、评论），本地播放体验向 B 站看齐
- **AI 增强**：用本地跑的 AI 模型提升画质与音质（不用联网，数据不出本机）

---

## 2. 技术选型（已定）

| 层 | 选型 | 说明 |
|---|---|---|
| 主程序 | **C++ / Qt 6**（QML 界面） | 用户明确要求 C++，性能好；QML 是 Qt 的声明式界面语言（写法类似前端，底层 C++ 原生渲染），兼顾性能与美观 |
| 播放器 | **libmpv** | 开源播放器 mpv 的引擎（C 接口），几乎所有格式通吃、硬解、倍速、滤镜，C++ 路线的最佳选择 |
| 数据库 | **SQLite**（Qt SQL 直连） | 单文件、零安装，歌单/视频/弹幕/评论全存这里 |
| 后端 | **Python 3.10 + FastAPI** 子进程 | 下载、弹幕评论抓取、AI 管线；与 C++ 主程序分离（本地端口通信），AI 崩了不影响播放 |
| 下载 | **yt-dlp** + **bilibili-api-python** | yt-dlp 对 B 站支持最完善（可登录账号下高清）；bilibili-api-python 抓弹幕/评论/视频元数据 |
| AI 画质 | **Real-ESRGAN**（腾讯开源，国内厂商） | 超分辨率：1080p → 4K，CUDA 加速（50 系显卡） |
| AI 音质 | **DeepFilterNet**（降噪）+ **R128**（音量统一，ffmpeg loudnorm 滤镜）+ **音频超分（AudioSR 先行 / FiPA-SR 目标）** | 详见 §5 |
| 显卡 | RTX 50 系（Blackwell） | CUDA 12.8+，PyTorch 需 cu128 版本 |

### 为什么 C++ 与 Python 分两个进程

Python 的 AI 库与 C++ 程序硬绑容易互相拖累（版本冲突、AI 崩溃连坐主程序）。拆开后：
- 主程序启动时拉起 Python 子进程，通信走本机端口（127.0.0.1）
- Python 服务崩了，C++ 主程序仍可播放本地歌单
- 各自独立升级

## 4. 功能清单

### P0 本地媒体（歌单器本体）
- 音频导入：拖拽 / 文件夹扫描；读标签（歌名/歌手/专辑/封面）；支持 mp3/flac/wav/m4a/ape/ogg
- 歌单：多歌单、增删改、手动拖排序、播放模式（顺序/随机/单曲/列表循环）
- 播放：底部迷你播放条、播放队列、进度记忆、倍速、LRC 歌词滚动
- 本地视频：直接导入播放

### P1 B 站体验（差异化灵魂）
- 下载：粘贴链接 → 解析（多 P 选集、画质选择、封面/简介/UP 主）→ 后台任务下载 → 入库
- 弹幕：下载存本地 → 播放器 B 站风弹幕（滚动/顶部/底部/彩色/屏蔽/密度调节）
- 评论：下载热评 + 楼中楼 → 视频页 B 站风格评论区
- 视频信息页：封面、简介、标签、BV 号、收藏夹

### P2 AI 增强（统一形态：离线增强 + 原版/增强版切换）
- 后台任务跑模型，产出「增强版」文件
- 播放时像 B 站切「原画/高清」一样一键切换原版/增强版
- 画质增强：Real-ESRGAN（1080p → 4K，CUDA）
- 音质增强：降噪（DeepFilterNet）、音量统一（R128）、音频超分（AudioSR → FiPA-SR）
- 增强任务中心：队列、进度条、结果管理

### P3 锦上添花（可选）
- 登录 B 站后发送弹幕同步回去
- 历史记录、稍后再看
- 首页仿 B 站布局（最近播放/收藏推荐）

## 5. AI 增强管线细节

### 5.1 画质增强（Real-ESRGAN）
- 腾讯开源（国内厂商），超分辨率模型，视频管线：ffmpeg 抽帧 → 逐帧 CUDA 推理 → ffmpeg 合帧
- 50 系显卡（Blackwell，CUDA 12.8+）速度理想，1080p 升 4K 可行
- PyTorch 需用 cu128 版本的 wheel（`--index-url https://download.pytorch.org/whl/cu128`）

### 5.2 音质增强
| 管线 | 工具 | 作用 |
|---|---|---|
| 降噪 | DeepFilterNet3 | 去底噪/电流声/风扇声 |
| 音量统一 | ffmpeg loudnorm（EBU R128 标准） | 不同视频音量拉平，播什么都一个音量 |
| 音频超分 | **AudioSR（先行）→ FiPA-SR（目标）** | 低采样率音频补回高频细节 |

### 5.3 FiPA-SR 接入策略（用户点名模型）
- **是什么**：音频超分辨率模型（FiLM 条件化感知音频超分），出自 [arXiv 2605.30594](https://ar5iv.labs.arxiv.org/html/2605.30594)，GAN 架构，单模型支持 8k/20k/32k 输入，超越 SOTA 的 AudioSR，推理快 60 倍、省 3 倍显存
- **现状**：2026-05 发布论文，**官方代码尚未开源**（2026-08 核实）
- **决策（用户确认）**：如果 FiPA-SR 接入不方便，先用 AudioSR 替代；架构上做「模型插槽」（统一接口：音频进 → 模型出 → 增强音频），FiPA-SR 一开源即接入，无缝替换
- 跟踪方式：定期检查 arXiv 页面 / 作者 GitHub（Wallace Abreu 团队，AEROMamba 同源）

### 5.4 模型插槽机制（backend/app/enhancers/）
```python
ENHANCERS = {}          # 名称 -> 增强器类
def register(name): ... # 装饰器注册
@register("audio_sr")
class AudioSREnhancer:  # 未来 FiPA-SR 同接口替换
    def enhance(self, src, dst, device="cuda"): ...
```

### Qt 说明

## 9. 关键技术决策记录

| 决策 | 结论 | 理由 |
|---|---|---|
| 主程序语言 | C++（Qt 6） | 用户要求，性能好 |
| 后端语言 | Python 3.10（本机现成） | AI 模型生态 + 用户认可；本机 3.14 太新不支持 AI 库，3.10 现成可用 |
| 音频超分模型 | AudioSR 先行 → FiPA-SR 目标 | 用户点名 FiPA-SR；未开源先用 AudioSR |
| AI 增强形态 | 离线增强 + 原版/增强版切换 | 稳定不卡，体验像 B 站切画质 |
| 进程架构 | C++/Python 分离 | 稳定性、解耦 |
| 下载工具 | yt-dlp | B 站支持最完善，支持登录高清 |
