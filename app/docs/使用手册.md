# 本地歌单器 · 用户使用手册

> 一句话：把 B 站体验搬到你电脑上的本地媒体管理器——本地音频歌单 + B 站视频下载（弹幕/评论）+ 本地 AI 音质画质增强。

---

## 1. 启动

- 双击项目根目录的 **`start.bat`**（推荐），或直接双击 `build\LocalMediaPlayer.exe`
- 程序会自动拉起 Python 后端服务（本机 127.0.0.1:8765），无需手动操作
- **核心功能零依赖**：弹幕、评论、480p 视频下载、响度增强都不需要安装任何额外软件

## 2. 音乐（本地歌单）

### 导入音频
- 首页 → 「➕ 添加文件」选多个文件，或「📁 导入文件夹」扫描整个文件夹（自动递归）
- 也支持直接把文件**拖进窗口**
- 支持格式：mp3 / flac / wav / m4a / aac / ogg / ape / wma
- 文件名形如「歌手 - 歌名.mp3」时自动拆分为歌手和歌名

### 歌单
- 左侧「歌单」→ 输入名称 → 新建歌单
- 点进歌单 → 下拉框选歌曲 → 「添加」；「移除」按钮可移除
- 点歌曲直接播放

### 播放
- 底部播放条：播放/暂停、上一首/下一首、进度拖动、音量
- 播放模式按钮：顺序 ▶ / 随机 🔀 / 单曲循环 🔂 / 列表循环 🔁
- 首页「最近播放」横向卡片，点卡片立即播放
- 播放历史自动记录，进度可拖动

## 3. 视频（B 站体验）

### 下载
1. 「下载中心」→ 粘贴 B 站链接（形如 `https://www.bilibili.com/video/BV1xx…`）
2. 点「解析」→ 显示标题/UP主/时长/清晰度列表
3. 选清晰度（默认自动，免登录最高 480p）→ 「开始下载」
4. 任务列表实时显示进度；完成后自动入库

### 弹幕
- 下载时自动抓取弹幕（如「从未」）
- 「视频库」→ 点「播放」→ 视频画面叠加 B 站风弹幕：滚动/顶部/底部、彩色、防重叠
- 弹幕随进度同步出现，可暂停查看

### 评论
- 播放页下方评论区自动加载（B 站热评排序，含点赞数）
- 未缓存的会实时抓取

## 4. AI 增强

「AI 增强」页：选媒体（本地歌曲或已下载视频）→ 选增强类型 → 开始增强 → 任务列表看进度

| 增强 | 说明 | 依赖 |
|---|---|---|
| 响度统一 | 音量拉平到 -14 LUFS（国际标准），不忽大忽小 | 无（ffmpeg）✅ 已可用 |
| 降噪 | DeepFilterNet，去底噪/电流声 | 需装 AI 依赖 |
| 音频超分 | AudioSR → FiPA-SR（目标），低音质补高频 | 需装 AI 依赖 |
| 画质增强 | Real-ESRGAN 4x 超分（1080p→4K） | 需装 AI 依赖 + 模型 |

增强完成后任务列表显示输出文件路径（`data\enhanced\` 目录）。

## 5. 可选增强（装包后解锁）

以下功能需要手动安装依赖（按你的习惯，命令给你自己执行）：

```bash
# ① 高清下载（1080p+，需登录可更高）：
cd F:\DSH\LocalMediaPlayer-Workspace\app\backend
py -3.10 -m venv .venv
.venv\Scripts\activate
pip install yt-dlp

# ② AI 增强（降噪/超分/画质）——需 Python 3.10 + NVIDIA 显卡：
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements-ai.txt
# 然后下载 Real-ESRGAN 模型到 backend\models\ 目录：
#   https://github.com/xinntao/Real-ESRGAN/releases/download/v0.1.0/RealESRGAN_x4plus.pth
```

## 6. 数据文件位置

| 内容 | 路径 |
|---|---|
| 数据库（歌曲/歌单/视频/弹幕/评论/历史） | `data\local_media.db` |
| 下载的视频 | `data\downloads\` |
| 增强产物 | `data\enhanced\` |
| 运行日志 | `data\qt.log` |

> 备份 = 复制 `data` 目录。

## 7. 常见问题

| 问题 | 解决 |
|---|---|
| 视频下载失败 | 检查网络；部分视频需登录（480p 免登录可下）；看任务列表错误信息 |
| 弹幕不显示 | 确认下载时弹幕抓取成功（任务完成后视频库弹幕数>0）；播放页弹幕数显示 |
| 没有声音 | 检查系统音量；播放条音量滑块；视频用 HEVC 需显卡硬解（默认软件解码兜底） |
| 评论为空 | 部分视频评论需登录抓取；可稍后重试（实时抓取） |
| 增强失败 | 查看任务错误；响度增强无需依赖，其他增强需装依赖+模型 |

## 8. 技术速览（给开发者）

- 主程序：C++17 / Qt 6.11（QML 界面）/ QMediaPlayer 播放
- 后端：Python 3.10 子进程，**纯标准库**（http.server + urllib + sqlite3）
- B 站接口：弹幕 XML（deflate 解压）、评论 wbi 签名、playurl DASH 流——全部零第三方依赖
- 构建：`cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH=E:/Qt/6.11.1/mingw_64 ...`（见方案设计文档）
